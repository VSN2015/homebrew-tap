# homebrew-tap

Homebrew formulae for [VSN2015](https://github.com/VSN2015)'s tools.

```sh
brew install VSN2015/tap/worktree-kit
```

| Formula | Description |
|---------|-------------|
| [worktree-kit](https://github.com/VSN2015/worktree-kit) | `wt` — per-worktree runner: commands, servers, and DB/Redis isolation for git worktrees |
